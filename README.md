# Upbit Momentum Auto Trader

업비트/코인원 시세를 기반으로 자동 매매 신호를 판단하는 Python/FastAPI 앱입니다. 데모 모드에서 가상 체결을 기록하고, 설정한 거래소와 자격 증명이 준비된 경우 실거래 모드로 실행할 수 있습니다. 수익은 보장되지 않습니다.

## 빠른 실행 (Linux)

Python 3.12 이상, Git, 사용자 systemd가 필요합니다. 최초 한 번 서비스를 설치한 뒤에는 서버를 한 줄 명령으로 켜고 끌 수 있습니다.

```bash
./trade install
./trade start
./trade stop
```

관리 명령:

```bash
./trade status
./trade restart
./trade logs
```

대시보드와 설정은 기본 포트 `8080`에서 열립니다.

- 대시보드: `http://127.0.0.1:8080/dashboard`
- 설정: `http://127.0.0.1:8080/settings`
- 상태 확인: `http://127.0.0.1:8080/health`

다른 기기에서 접속할 때는 `127.0.0.1` 대신 서버의 로컬 네트워크 IP를 사용하세요. 서비스 중지는 앱 서버와 자동매매 루프를 함께 중지합니다.

## 설정과 거래 모드

실행 설정은 저장소에 커밋하지 않는 `.env` 파일 또는 `/settings` 화면에서 관리합니다. 필요한 초기 값은 `.env.example`을 참고하세요.

- `demo`: 거래소 주문 없이 가상 체결을 기록합니다.
- `live`: 선택한 거래소에 실제 주문을 제출할 수 있습니다. 거래소 API 키, 잔고 동기화, 주문 복구 상태와 실거래 허용 설정이 필요합니다.
- 실거래 API 키와 Telegram 토큰은 README, 로그, Git 커밋에 넣지 마세요.

`/settings`에서 거래소, 거래 모드, 투자 성향, API 키, Telegram 알림을 설정합니다. Codex 자동 룰 개선은 `gpt-6-astra`를 사용하며, 로그 분석 후보를 replay로 검증한 변경만 반영합니다. 승인된 룰은 데모에 즉시 적용되고 동일한 룰 상태로 저장되어 실거래 모드에서도 불러옵니다.

대시보드에서는 자동매매 루프 실행 여부, 장세, 최근 체결, 손익, 최근 24시간 수익률, 일일 목표 달성률과 A~R 데모 룰 상태를 확인할 수 있습니다. 일일 목표는 기준 투자금 대비 `+0.10%`이며 목표 진행은 최근 24시간 수수료 반영 실현 손익으로 계산합니다.

## Telegram 알림

Telegram 설정을 완료하면 체결, 시장 급변, 서버 복구, 안전 정지, 룰 전환과 주간/일일 성과를 구조화된 한국어 메시지로 받습니다. 매도 알림에는 개별 매도 손익과 최근 24시간 목표 진행률이, 매일 오전 08:00 KST 리포트에는 목표 진행, 체결 현황, 승률, 누적 손익이 표시됩니다.

## 주간 GitHub 수익률 업데이트

주간 리포트는 로컬 체결 원장을 사용합니다. 매주 월요일 09:00 KST에 직전 월요일부터 일요일까지의 체결을 집계하고, README 기록을 한국어 커밋으로 만들어 `origin/main`에 푸시합니다.

```bash
./trade install-weekly-report
./trade weekly-report
```

첫 명령은 사용자 systemd 타이머를 설치합니다. 둘째 명령은 같은 집계를 즉시 실행합니다. 예약 실행 상태와 로그는 다음 명령으로 확인할 수 있습니다.

```bash
systemctl --user list-timers weekly-readme-report.timer
journalctl --user -u weekly-readme-report.service --since '7 days ago'
```

자동 집계는 해당 주간에 청산된 수량의 수수료 반영 순손익을 매입 원가로 나눈 실현 수익률입니다. 미청산 포지션은 제외하며, 매도 체결이 없으면 `미집계 (청산 없음)`으로 남깁니다. README에는 모드, 시장, 거래 횟수, 승률, 수익률만 공개하고 주문별 내역과 원화 금액은 기록하지 않습니다.

GitHub 푸시를 위해 이 컴퓨터의 `origin`에 쓰기 권한이 있는 Git 인증이 설정되어 있어야 합니다. 자동 작업은 `main` 브랜치와 깨끗한 작업 트리에서만 진행합니다. 수동 변경이나 일반 로컬 커밋이 있으면 README를 덮어쓰거나 자동 푸시하지 않고 서비스 로그에 보류 사유를 남깁니다.

## 개발

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e .
uvicorn app.main:app --host 0.0.0.0 --port 8080 --reload
```

거래 기록, 학습 로그, 실행 상태 파일은 `storage/` 아래에 저장되며 Git 추적 대상에서 제외합니다. 이 데이터는 룰 검증과 주간 수익률 집계에 필요하므로 운영 서버에서 삭제하기 전에 백업하세요.
